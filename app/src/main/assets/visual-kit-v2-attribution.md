# Wildflower Lens visual asset kit V2

The `wf_*` resources were supplied by the project owner in
`Wildflower_Complete_Visual_Asset_Kit_v2/visual-kit-v2`, on 2026-10-11.
The original ASSET_MANIFEST.json records their provenance and SHA-256 hashes.
They include generated/derived editorial imagery, illustrations, programmatic paper
textures, template bases and vector icons, not independently verified field photography.

Editorial imagery is not an identification certificate, user observation or licensed
CC photograph. It is limited to public editorial areas and explicitly labelled empty
season imagery. Personal records and PNG exports use actual observation URIs.
Blank stamps are decorative, not museum accreditation. Reference screen designs are
not packaged as UI assets. No unapproved cultural text is introduced by this kit.

Before release or competition submission, review generated/derived asset eligibility
and existing third-party/font/photography licences. This attribution does not invent
a licence or claim that every third-party permission has been independently verified.
Existing upstream, font and photography notices remain in place; authoritative
upstream licence verification remains an open release requirement.
